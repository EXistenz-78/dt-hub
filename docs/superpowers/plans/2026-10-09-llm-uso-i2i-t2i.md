# Usi I2I e T2I degli LLM — Piano di implementazione

> **Per chi esegue:** SOTTO-SKILL OBBLIGATORIA: `superpowers:subagent-driven-development` (consigliata) oppure `superpowers:executing-plans`. I passi usano la sintassi a caselle (`- [ ]`).

**Obiettivo:** due usi nuovi nel menu Uso delle Preferenze › LLM: I2I (vale come Entrambi solo con immagini in Control) e T2I (solo con Control vuoto).

**Architettura:** `LanguageModelUse.covers` riceve il contesto; il router e il manager ricevono `LanguageModelNeeds` (contesto + visione) al posto di `needsImages`; l'assistente calcola il contesto da `EnhanceImages`; le Preferenze hanno due voci; Prompt Master accetta `t2i`.

**Tecnologie:** Swift 6.2, Swift Testing, SwiftUI.

**Spec:** `docs/superpowers/specs/2026-10-09-llm-uso-i2i-t2i-design.md` (tabella di `covers` al §3).

## Vincoli globali

- **Prerequisito:** «Migliora con immagini» unita in `main`. Prima di partire, controllare i nomi reali che ha introdotto (`EnhanceImages`, il parametro `needsImages`, `Note.imagesNotSent`) e adattare i riferimenti di questo piano se differiscono.
- Ramo nuovo (es. `llm-uso-i2i-t2i`). **Niente unione, push o release senza via libera esplicito.** File aggiunti **per nome**.
- Test: `cd Packages && swift test --filter <Suite> 2>&1 | grep -E "Test run with|error:"`; plug-in: `cd Plugins/PromptMaster && swift test …`.
- App: `xcodebuild -project DTHub.xcodeproj -scheme DTHub -destination 'platform=macOS' -derivedDataPath build build`.
- I test esistenti restano verdi; cambia solo il modo di passare il contesto (`covers(_:)` → `covers(_:controlHasImages:)`, `needsImages:` → `needs:`), da aggiornare nei test senza cambiare le attese.
- Testi it/en (`Localizable.xcstrings`, `extractionState: manual`). Commenti in inglese.

## Review Focus

1. Impostazioni salvate prima di questo lavoro (usi vecchi): si leggono uguali (Task 1).
2. Genera Prompt con un LLM su T2I come unico candidato: non viene scelto (`.noModelSelected`), mai usato per Genera (Task 1–2).
3. Sola Moodboard accesa su una famiglia che non la legge (SDXL): Control conta come vuoto → T2I (Task 3, già garantito da `EnhanceImages`).
4. I2I senza visione, Control con immagini: scelto nel ripiego e riceve solo il testo con la nota (Task 2–3).
5. La coppia PE T2I / PE I2I sulla stessa famiglia non produce avvisi di precedenza (Task 2).
