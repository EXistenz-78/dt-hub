# CU Meter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Con DT+ acceso, mostrare nell'header, accanto a «DT+», quante Compute Units (CU) richiede il RUN rispetto al limite per RUN, con i boost necessari.

**Architecture:** Il calcolo ufficiale di Draw Things (`ComputeUnits.swift` e i conteggi delle istruzioni per famiglia) è portato in `DTBridge` (solo lì); tipi e matematica dei boost neutri in `HubKit`; un pianificatore puro in `HubCore` trasforma parametri, Control e pipeline in «passaggi» da stimare; la vista sta nell'app. Le soglie vengono dall'echo a `compute.drawthings.ai` (lo stesso di `CloudCatalog`).

**Tech Stack:** Swift 6.2, SwiftUI, Swift Testing (`import Testing`, `@Test`), DrawThings-Swift 2.2.0 (`DrawThingsClient`, già nel progetto).

**Spec:** `docs/superpowers/specs/2026-10-15-cu-meter-design.md` (leggerla prima: fonti, formula, decisioni).

## Review Focus

Casi che la spec non nomina e che le prove dei task non coprono da sole (ognuno ha il suo test nel task indicato):

1. **Valori a zero o enormi** (passi 0, dimensioni 0, 8192×8192, batch 64): le primitive ufficiali hanno `precondition` che fanno crashare; la stima deve restituire `nil`/0 senza trappola (Task 4).
2. **Policy scaduta o echo con `plus = 0`:** si ignora e vale il predefinito 40 000; una policy attiva (per esempio 20 000) vale fino a `expireAt` (Task 2, Task 9).
3. **Cache vecchia di `dtplus-files.json`** (formato lista di file, senza soglie) deve ancora leggersi (Task 9).
4. **Pipeline con preset o modello mancante:** quel passaggio vale «—» e gli altri si calcolano; il misuratore non lancia errori (Task 10).
5. **Moodboard su una famiglia che non lo usa** (`FamilyTraits.usesMoodboard == false`): le immagini di riferimento non contano (Task 10).
6. **DT+ spento a metà RUN:** la vista sparisce senza lasciare un'attività di lettura in corso (Task 12).
